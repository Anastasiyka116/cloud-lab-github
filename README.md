# Лабораторна робота №5: Хмарні технології
## Опис проєкту
Цей проєкт демонструє роботу з Git, GitHub Actions та GitHub Pages в рамках лабораторної роботи.

Навчитися керувати версіями коду, налаштовувати CI/CD автоматизацію та публікувати статичні вебсторінки.

## Інструкція запуску
